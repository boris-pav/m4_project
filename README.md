# Консольная игра "Спички"

## Игровая логика
Программа сначала запрашивает количество спичек в начале игры. Затем программа спрашивает, кто ходит первым (игрок или компьютер). В свой ход игрок вводит число от 1 до 3 (сколько спичек взять). Если игрок вводит неправильное число (не 1-3 или больше, чем осталось), программа просит ввести заново. Компьютер ходит по стратегии: берёт столько спичек, чтобы оставить противнику число, кратное 4. Если осталось меньше 4 спичек, компьютер берёт все, кроме одной (или одну, если нужно). Игрок, который забрал последнюю спичку, проигрывает. После окончания игры выводится сообщение о победителе и предлагается сыграть ещё раз.

Правила игры в "Спички"

На столе лежит кучка из N спичек (обычно 10-20 штук). Два игрока ходят по очереди. За один ход игрок может взять от 1 до 3 спичек. Игрок, который забирает последнюю спичку, проигрывает. Игра продолжается, пока спички не закончатся.
